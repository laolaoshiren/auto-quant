## 0. 结论摘要（一句话）

```
模拟盘的成交是本地模拟的、从不真的下单，而 `getPositions()` 去查真实交易所
⇒ 恒返回空 ⇒ 对账把【每一个】本地持仓判成"已在交易所消失"并平掉
⇒ 团队模式的仓位【活不过一个周期】：实测 37 笔平仓 p50 = 3.8 分钟，
  【0 笔超过 15 分钟】，而实盘对照 p50 = 109 分钟、94% 超过 15 分钟
```

**它一直在"开仓 → 被自己对账平掉 → 再开仓"地空转。**

修复后（真实日志证据）：
```
05:04:13  已开仓 ZEREBROUSDT 多头 263 @ 0.04276569（5x，$11.25）止损 0.041033 止盈 0.043143
05:07:32  [模拟盘] ZEREBROUSDT 多头 的止盈 0.043143 已被标记价 0.04319473 触发，按触发价结算
05:07:32  已平仓 ZEREBROUSDT 多头 @ 0.043143 → 净 +0.0879 USDT（毛 +0.0992，含手续费 0.0113）
```
**原因是从触发事实推出来的、成交价是触发价、手续费真实计入。**

## 2. 根因链

```
① `simulateAlgo()` 建完单就不管 —— 保护单永远停在 NEW（没有价格触发的模拟）
② `getPositions()` 【没有 dryRun 守卫】→ 真去查交易所 → 恒返回空
③ `reconcilePositions()` 看到"本地有、交易所没有" → `bookVanishedPosition()`
   → `lastFillFor()` 拿"该标的最后一笔成交价"当 exitPrice
     ⚠️ 账户 2 上还有 #9 在交易 —— 那可能是【#9 的成交价】
   → `detectCloseReason()`：`getAlgoOrder` 有 dryRun 守卫 → 判不出
   → 走 `reasonFromPrice()` 猜
④ `positionStore.close()` 把仓位抹掉
```

### 2.1 四个静默失效（同一个根因）

`getPositions()` 在模拟盘上恒空，于是这些地方**都不报错、界面看不出异常**：

| 位置 | 修复前的行为 |
| --- | --- |
| `reconcilePositions` | 把每个本地持仓判成"已消失"并平掉 ← **主症状** |
| `applyDrawdownGuard` | 空列表 → 回撤守卫**从不触发** |
| `applyBreakevenGuard` | 空列表 → 保本/移动止损**从不触发** |
| `recordEquity` | 浮盈恒 0 → 权益曲线是平的 |

## 3. 修法

新增 `effectivePositions()` —— **一处生效、处处生效**：

```
实盘   → 直接转发 broker.getPositions()（交易所是唯一真相来源）
模拟盘 → 用本地 positions 行 + 【真实标记价】合成
```

⚠️ 标记价是**真实行情**（不是模拟的），所以模拟盘的浮盈是可信的。

⚠️ 没有给四个调用点各写一个 `if (isDryRun)` 分支 —— 那正是"只做一半"的温床
（本项目为此吃过四次亏，用户原话：「你做事情只做一半？？」）。

新增 `settleDryRunPositions()` —— 模拟盘**真的结算保护单**：

```
做多：标记价 ≤ 止损 → 触发止损（以【止损价】成交）
      标记价 ≥ 止盈 → 触发止盈（以【止盈价】成交）
做空：反过来
都没碰到 → 继续持有（并更新回撤守卫用的峰值）
```

⚠️ 成交价用**触发价**而不是标记价：真实条件单触发后就是按触发价成交的，
用标记价会让"止损距离"的归因被污染。
⚠️ 两个都碰到时**止损优先**（保守方向 —— 少赚好过多亏）。
⚠️ 手续费复用策略里已有的 `fallbackRoundTripFeeRate`（默认 0.1%）——
记 0 会让模拟盘看起来比现实更容易赚。

### 误报 2：「positions 表有 37 行幽灵持仓」

**实际**：那 37 行全是 `status='closed'`，而 `positions.open()` 查的是
`status='open'` → **0 行**。UI 显示「当前持仓 0」是对的。
我看到了"37 行"就推断"UI 该显示 37"，**没有先确认查询条件**。

⚠️ **同一个错误在 24 小时内犯了两次**：把"我的查询看到的东西"当成事实，
而没有先确认**查询条件**。这正是 `docs/AGENTS.md` §3.2 那条纪律要防的。
