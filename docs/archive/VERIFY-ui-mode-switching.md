# 需求⑥「UI 适配 + 现模式保留 + 用户可切换」验证记录（2026-10-15）

> 用户原话：
> > 「这次大版本更新后，现在得决策那块 UI 应该就不适用了，应该怎么改才能适配这次大版本更新，
> >  由你来统筹设计（**现阶段得也得保留**，因为这次大更新做增量，也就是说最终更新完了以后，
> >  **现阶段得这种模式也得保留，用户可以自行切换**用现有模式和我这次想增加更新得这种模式）」

**结论：三条要求都已实现，且用真实浏览器验证过。**

---

## 1. 三种模式都在，用户可切换（截图确认）

「新建机器人」弹窗的「运行方式 → 运行模式」有三个单选项：

```
● 按策略参数
    用下面选中的策略里的固定参数跑。**行为与以前完全一致。**
○ AI 智能托管（全自动）
    参数与交易提示词全部由 AI 自主设定并实时调整：周期、标的池、杠杆、仓位、
    止损止盈、节流与冷却。以盈利为唯一目标，并根据真实交易结果不断反思、迭代。
○ AI 团队（多智能体 · 7×24）
    一支分工协作的智能体团队：调度官统筹，分析师并行调研（行情、新闻、社区情绪），
    多空研究员对抗辩论，风控官把关，交易员执行。持续工作、事件驱动，
    每次决策都有完整审计轨迹。
```

⚠️ 第一项的文案是「**行为与以前完全一致**」—— 这正是"增量更新"该有的承诺。

后端对应的枚举（`server.ts:274`）：
```ts
mode: z.enum(['strategy', 'ai_managed', 'ai_team']).default('strategy')
```

## 2. 现模式的界面**逐字节未变**（用真实机器人对照）

判据：团队看板只在 `mode === 'ai_team'` 时渲染（`DecisionFeed.tsx:585`）。

```
#10（ai_managed，实盘）：16,528 字可见文本 · 团队看板=false · 团队角色词=false
#11（ai_team，团队）    ： 6,966 字可见文本 · 团队看板=true  · 团队角色词=true
```

⇒ **`ai_managed` 的界面里完全没有团队看板的痕迹** —— 现模式没被改动。

## 5. ⚠️ 一处小瑕疵（不影响功能，如实记下）

界面里「AI 团队」的描述用词是「**调度官**统筹」，
而团队看板与提示词里那个角色的名字是「**总管**」（`supervisor`）。

**同一个角色两个叫法** —— 不构成 bug（功能正常），但会让人多花一秒确认
"这两个是不是同一个岗位"。若要统一，改 `TraderModals.tsx` 那句文案即可。
