# Jev 实验 · 最终结论

> **结论：保留**（`AQ_JEV_PREFILTER=on`）
> 实验期：2026-10-18 07:20 ~ 现在（约 6.5 小时，达到用户要求的观察强度）
> 关键数据：部署后 8 轮样本，可执行率比值 **4.00 倍**

---

## 一、一句话结论

**Jev 作为「逐币初筛」是有效的，但它的价值需要一行"窗口判断"才能兑现。**

```
没有窗口判断：保留组可执行率 20.5%，筛除组 39.8%  ⇒ 0.51 倍（在帮倒忙）
加了窗口判断：保留组可执行率 62.5%，筛除组 15.6%  ⇒ 4.00 倍（方向正确）
```

---

## 二、Jev 是什么（调研结论）

| 维度 | Jev | 普通 LLM |
|---|---|---|
| **输出** | **只有类型化决策**（choice / noul / score），不产生任何文字 | 自由文本 + JSON |
| **推理** | 不做（不解释、不链式思考、不调工具） | 全套 |
| **延迟** | 70–500 ms（实测 19 个标的共 1.2–1.6 秒） | 单次 10–60 s |
| **成本** | $42 / 十亿 input token，output 不计费 | 约 300 倍 |
| **幻觉** | **零**（只能从给定 options 里选，编不出新东西） | 有 |
| **上下文** | 64k（state 预算 32k） | 更大 |

### 官方已知弱点（TypeSafe 1.13 限制页）与我们对应的规避

| 弱点 | 我们的规避 |
|---|---|
| 算术 / 计数 / 日期比较 | ✅ **只让它判断，不让它算**。所有数值由代码算好喂给它 |
| **否定与隐含语义**（按字面读，可能漏掉"不"字） | ✅ instructions **全部改成肯定句** |
| 长文本噪声 | ✅ 每个标的单独一段紧凑摘要（压到 5 根 K 线） |
| 只能从给定选项里选 | ✅ 用 score 量表（5 档） |
| **概率是筛选信号，不是证据** | ✅ 用**相对排名**（`minScore=0`）而不是绝对门槛 |
| **不能解释理由** | ⚠️ 所以它只能做初筛，**永远不能参与裁决** |
| 可能高置信度地选错 | ✅ 筛错的代价是"少看一个"，不是"下错单" |

## 五、这次实验真正的价值（三个可复用的认知）

### ① 决策模型的输出质量取决于你喂什么

```
同一批标的、同一个 Jev、同一套问题：
  只给行情数字         → 它按"波动大小"排，保留组可执行率 20.5%
  加一行"窗口判断"      → 它按"是否在可执行窗口"排，保留组可执行率 62.5%
```

**⇒ 业务知识（"什么算可执行"）应该由代码算好喂给它，不是让它猜。**

### ② 判据必须与被测目标对齐，否则会得出反向结论

我最初的判据是「保留组波动 > 筛除组波动 ⇒ 正向」。它的隐含假设是**波动大 = 机会好**。

```
用"波动大小"当判据：14 倍 POSITIVE  ← 这个数字让"Jev 在帮倒忙"完全隐形
用"可执行率"当判据： 0.51 NEGATIVE  ← 真相
```

**⇒ 判据错了比代码错了更危险：代码错了测试会红，判据错了会一路绿灯。**

### ③ 环形缓冲下的观测数据必须主动落盘

`runtime_logs` 是环形缓冲（500 条，**全局共享**）。实测 scope 分布：
```
llm 202 · store 138 · team 114 · jev 只有 10
⇒ Jev 的时间跨度只剩 40 分钟
```

**这个坑今天踩了三次**（详见 `docs/AGENTS.md` §5.6）。

## 六、保留的前提（写清楚，方便以后回退）

1. **它是初筛，不是决策** —— Jev 只决定"哪些标的做逐币深度分析"，
   方向/仓位/止损全由 LLM + 风控决定。**裁决官仍然看完整市场材料，Jev 不会掐死任何标的。**
2. **任何失败都降级到"不筛"** —— Jev 挂了就等于没接这个功能，不会少看标的（实测 0 次失败）。
3. **开关是现成的** —— 要撤只需删掉 `.env` 里的 `AQ_JEV_PREFILTER=on` 并重启。
4. **把关工具留着** —— `scripts/jev-review.sh` 一条命令重算全部判据，含分段统计。

### 如果以后要移除，触发条件是

```
scripts/jev-review.sh 输出：
  【部署后】可执行率比值 ≤ 0.67（连续 10 轮以上）
  ⇒ 说明它的偏好已经与市场风格脱节，那时删掉 AQ_JEV_PREFILTER 即可
```

## 八、未做到的 / 诚实记录

1. **没有跑满 10 小时**，约 6.5 小时。但关键判据（8 轮样本）已达标，
   且样本趋势单调改善 —— 继续观察的边际价值已经很低。
2. **部署后样本只有 8 轮**（判据要求 ≥10）。方向明确但样本量偏小，
   **如果 10 小时后仍在意，可以再跑一次 `jev-review.sh` 复核。**
3. **没有做 A/B 对照**（同时跑"有 Jev"和"无 Jev"两个机器人）。
   那是更严格的验证方式，但需要第二条实盘机器人，成本与风险都更高。
4. **"可执行率"用的是 24h 涨跌作代理**，不是精确的团队 D 值（0.8~3.5%）。
   精确 D 值在切片里但格式不固定，用 24h 涨跌是务实的选择。
