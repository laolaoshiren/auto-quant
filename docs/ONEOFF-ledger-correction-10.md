## 2. 根因（代码侧已修，见 `4efe27b`）

那 38 笔的金额是按 **「标的 + 时间窗口」** 从 `income` 聚合的。而那些窗口：

```
p50 6.3h · p90 97.2h · 最大 159.3h      （其他平仓类只有 2–3h）
```

窗口跨过了多个真实回合 —— 那些回合**各自已经记过账**，却又被这个窗口聚合了一遍。

**修法**：`income.tradeId` **等于**成交的 `id`（实测 `NEARUSDT`：19 条 `REALIZED_PNL`
与 33 笔成交，**19/19 全部对上**）。所以改按成交 id 精确归属。

## 5. 一个我差点犯的错（记录）

我第一次算"账本 vs 全账户流水"得到 **差 43.75**，并一度准备按它校正。查清后发现：

```
账户 3 上只有 #10 一个机器人 ✅ 归属干净
但 #10 创建于 10-03T03:01，而 income 里有 BTWUUSDT 10-02T11:03 的成交
⇒ 那 92 条 REALIZED_PNL（合计 -36.48）【早于 #10 创建】，不属于 #10
```

**正确判据是用与平台同一个时间窗**（`#10 创建时间 − 60s` 起）。用该窗口独立重算得到
`-7.2532`，与平台自己算的 `exchangeNet` **差 0.0000** ⇒ 口径确认一致。

⚠️ 教训：**"账本 vs 全账户"不是同一个口径**。用错窗口会得出 43.75 这个虚高的差额，
而按它改数据会把别人的盈亏算到 #10 头上。
