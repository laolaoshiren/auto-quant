## 四、⚠️ 时间戳：我在这个问题上错了四次，记下来

本次差点因为读错时间去做无用的排查：`agent_last_wake:8 = 05:33:05Z`，
我把它当成"8.5 小时前"，而**服务器是 CST（UTC+8），实际只有 33.8 分钟**。

本会话四次同类错误：

| # | 错法 | 后果 |
| --- | --- | --- |
| 1 | **格式**不匹配（`datetime('now')` 的空格格式 vs 库里的 ISO） | 读出"8 分钟新增 769 条"这种不可能的数字 |
| 2 | **时区**不匹配 | 误判"周期停了"，去查不存在的故障 |
| 3 | **凭估算写**（header 写 00:52，实测 00:45） | 日志里的时间不是观测值 |
| 4 | **又是时区**（把 UTC 读成本地，8.5 小时 vs 33.8 分钟） | 差点又去查一个不存在的问题 |

**规则**：库内所有 `*_at` / `timestamp` 都是 **UTC ISO**，服务器是 **CST**。
**要比较就把两边都转 epoch，或者像本文这样把对照显式打出来 —— 不要靠脑子换算。**
（`ports.ts` 里已经按这条实现；错的是我读日志时的习惯。）
