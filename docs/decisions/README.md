# 决策记录（ADR）

> **为什么有它**：重要决定如果只留在对话里，换会话就丢；写进这里，任何新会话都能查到"为什么这样定"。
> **什么时候写**：做了一次会影响后续多个迭代的选择（架构、流程、依赖、边界）。
> **命名**：`ADR-<四位序号>-<短横线主题>.md`，序号递增、不复用。
> **模板**：复制 `ADR-0000-template.md`。
