# ADR-0004：UI 模板收敛为 quill（静谧），删除 classic / console

- **状态**：已采纳
- **日期**：2026-11-10
- **决策者**：用户（要求"3 套保留一套最合理"）与 AI（依据阶段 A 量测报告）

## 背景

前端有三套布局模板（`packages/web/src/templates/`）：

- `classic`（444 行）：顶部导航 + 单列内容区，原版外观，只有深色。
- `console`（1686 行）：菜单栏 + 侧栏 + 窗口隐喻，深浅色。
- `quill`（2454 行）：侧栏 + 分段控件 + 工具栏，深浅色。

用户要求只保留一套并彻底修好 UI/UX。维护三套意味着每次页面改动都要在三套外壳里验证、
契约测试要跑三遍、文档要维护三份表述 —— 长期成本高且容易漂移。

## 评估（真实无头 Chrome 量测，65 张截图 × 13 路由 × 深浅色）

| 维度 | classic | console | quill |
|---|---|---|---|
| 深/浅色 | 仅深色 | 有 | 有 |
| 工具栏（页面动作统一挂载） | 无（就地渲染） | 有 | 有 |
| 导航 | 顶栏 + 设置下拉 | 菜单栏 + 侧栏（同一份导航两处） | 侧栏 + 分段控件（分层） |
| 内容可用 @1600×900 | 1600×844 | 1348×710（外壳吃 15% 宽 / 21% 高） | 1388×774 |
| 浅色对比度不达标 | — | 27/436 | **1/432** |
| 键盘焦点缺失 / 移动端溢出 | 0 / 0 | 0 / 0 | 0 / 0 |
| 控制台错误 / 空白页 | 0 / 0 | 0 / 0 | 0 / 0 |

## 决定

**保留 `quill`，删除 `classic` 与 `console`。**

理由：

1. 唯一「功能完整（工具栏 + 深浅色）+ 导航分层不冗余 + 浅色对比度最好 + 内容空间足够」。
2. `classic` 缺工具栏/深浅色/状态栏，修到"彻底修复"等于重写，且与其"原版逐字保留"的定位冲突。
3. `console` 菜单栏与分组侧栏是同一份导航的两份呈现；浅色窗口隐喻弱化；常驻内部指标违反
   控制台设计约定（内部指标默认不出现）。

## 影响

- 阶段 B：删除两套 + 清理 registry/themes/index.html/AppearancePage/契约测试/文档"三套"表述。
- 修复 quill 的 P0/P1 问题（表格底部遮挡、markdown 残留、启动异步态、401、对比度、截断 title）。
- 以后新增 UI 只需要在一个外壳里验证；`ids.ts` 的 DOM 契约保持不变。
- 回滚方式：`git revert` 该 convergence 提交（两套模板在历史里仍可取回）。
