## 二、★ 补最后一个用例时发现的缺陷，比那个用例本身更重要

`FakeBroker.getPositions()` 里，浮盈是**硬编码的**：

```ts
unrealizedPnl: 0,
unrealizedPnlPercent: 0,
```

**于是任何依赖浮盈的逻辑在测试里从未被真正走到过** ——
保本止损每次都读到 0%、永远不触发，**而用例照样全绿**。

**这比"断言写得松"严重得多**：不是断言不够强，而是
**夹具让被测的那条分支根本不可达**。

> **一条永远不被执行的保护逻辑，和一个坏掉的保护逻辑，
> 在测试报告里长得一模一样。**

修成按当前标记价真算（价格变动百分比 × 杠杆，交易所口径）之后，
**既有的 39 个用例仍然全绿** —— 说明那个硬编码的 0 没有在掩盖别的东西。

**这一点值得单独记**：如果当时有别的用例因此变红，
说明它还掩盖了第二个问题。**夹具的"沉默"和代码的"沉默"一样危险。**
