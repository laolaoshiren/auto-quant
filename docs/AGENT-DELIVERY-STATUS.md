## 五、我在这一轮连错的同一个模式（三次）

可达性体检这个函数，我错了三次，**而三次是同一件事**：

1. **编了一个 `EXCHANGE_MIN_NOTIONAL_USD = 5`**（把推测当事实；真值按标的不同）
2. **漏了 `maxMarginUsage` 那一层**（把一层当全部；真上限 13.66 而不是 27.33）
3. **把「评了 2 个标的」说成「机器人会永远空转」**（把有限的检查说成无限的结论）

**三个都是"用编造的/不完整的信息给出确定的结论"。**
而这类错误的代价不在代码里 —— **在操作员据此做出的决定里**。

这与我最初把"机器人不交易"解释成"策略保守"是同一个毛病：
**我倾向于给一个听起来合理的解释，而不是承认"我还没查清"。**
