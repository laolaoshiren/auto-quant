## ⚠️ 两条审计表述需要修正（我核实后发现的）

### A. 「`ROLES` 里 6/10 角色的提示词没送到」—— 不准确

真相（实测 `tradingDesk` 源码里的 `role: 'x'` vs `ROLES` 的键）：

```
tradingDesk 问 10 个角色，其中【7 个根本不在 ROLES 里】：
  bear · bull · judge · newscaster · sentiment · supervisor · technical
  ⇒ 它们【从来没有提示词可送】—— 不是"接线漏了"，是【编制表不完整】

ROLES 里有的 4 个（risk_officer / market_analyst / reporter / symbol_scout）
  → 本次修复后已能送达
```

**这个区别很重要**：前者要"补提示词"（写 7 份），后者是"接线"（已修）。
混为一谈会让人以为修完接线就万事大吉。

⚠️ 而 `judge`（裁决官）与 `bull`/`bear`（多空对抗）**没有提示词**是**决策核心的缺口** ——
它们目前只靠 `tradingDesk` 里的内联 task 短句工作。**这是待办，不是已修。**

### B. 「`symbol_scout` 未送达」—— 是我测试环境的问题，不是代码缺陷

```
它只在 AQ_PER_SYMBOL=on 时被问（线上确实开着）
而我的测试没设这个环境变量 → 那一轮压根没问它 → 测试报"未送达"
```

**教训：判据要能覆盖到目标，否则会让人去修一个不存在的 bug。**

