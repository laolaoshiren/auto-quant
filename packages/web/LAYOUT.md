# 界面布局与密度规范

本文档是 [`DESIGN.md`](DESIGN.md) 的补充，定义**页面骨架**与**信息密度**。
配色与字号见 DESIGN.md 与 [`tailwind.config.js`](tailwind.config.js)。

---

## 1. 页面骨架：左指标栏 + 主内容区

**这是本次改造的核心决定。** 起因是实际操作者的反馈：

> 顶部一行挤了八段同等权重的文字，扫一眼不知道哪个重要；
> 权益曲线占了 40% 屏高却只画出一条平线，而最该看的决策流被挤到屏幕底部要滚动。

问题的本质是**所有信息平铺在同一个垂直流里**，没有主次。

### 结构

```
┌──────────────────────────────────────────────────────────────┐
│  页头：标题 + 状态徽章 + 主要操作              （常驻一行）    │
├──────────────────┬───────────────────────────────────────────┤
│  指标栏 280px     │  主内容区（占满剩余宽度）                  │
│                  │                                           │
│  ── 账户 ──       │  ── 最近决策 ────────────────────────      │
│  归属权益 10.2586 │  周期 #40  成功  本周期没有决策            │
│  今日盈亏 $0.00   │  周期 #38  被拒 2  开多 BTCUSDT           │
│                  │  周期 #37  成功  开多 XRPUSDT             │
│  ── 交易 ──       │                                           │
│  胜率 0.0%        │                                           │
│  持仓 / 挂单 0/0  │                                           │
└──────────────────┴───────────────────────────────────────────┘
```

### 规则

- **`xl` 及以上**：左栏 280px 固定，主区占剩余宽度。
- **`lg` 及以下**：左栏塌成顶部的一行指标（横向滚动或换行），主区单列。
- 左栏**按语义分组**（账户 / 交易 / 系统），组间用一条细线 + 小标题分隔。
  不要把所有指标堆成一个列表——分组本身就是层级。
- **指标栏里只放状态，不放诊断值。** 见 §3。
- 主区**宽度全部给内容**。决策卡、表格、图表都能用满，不要在主区里再切窄栏。

### 什么时候不用这个骨架

**列表页**（机器人列表、策略列表、市场行情）用**整宽表格**，不要套左指标栏——
它们的内容就是一整张表。左指标栏适合"一个对象 + 它的很多细节"这种页面。

## 2. 信息密度

当前的问题是**密度过低**：1600×900 上大量空间被浪费，操作者要频繁滚动。

| 元素 | 之前的做法 | 现在 |
| --- | --- | --- |
| 表格行 | `py-3`（很高） | `py-2` |
| 卡片内边距 | `p-4` | `p-3.5` |
| 指标卡之间 | 大间距 + 大卡片 | 指标栏里用紧凑的行，不用卡片 |
| 决策流每条 | 大卡片 + 大内边距 | 按行排列，卡片只在需要强调时用 |

**判断标准**：在 1600×900 上，一个机器人详情页应该**不用滚动就能看到**
核心指标 + 持仓 + 最近几轮决策。

### 但密度不等于拥挤

- 分组之间要有**明确的空白**（`gap-5` 以上），组内才紧凑。
- 数字与标签之间保持呼吸感，不要贴在一起。

---

## 3. 诊断值不进主界面

**只显示状态，不显示内部指标。** 这条已经有教训：

顶栏曾常驻 `时钟 +22 ms` 和 `权重 59/2,400`。它们在正常运行时永远"没事"，
看一百次有九十九次拿不到信息，却占着最显眼的位置（操作者原话："似乎毫无意义"）。

**规则**：

- 内部指标（时钟偏移、API 权重、快照数量、token 明细）**默认不出现**。
- **越界时才显示**，并且要带**后果**而不是原始数值：
  `⚠ 时钟偏差 2.4s`（悬停说明会导致 `-1021`）比 `时钟 +2400 ms` 有用。
- 需要常驻诊断的场景（如交易所诊断页）可以显示，但要放在**专门的区块**里，
  不要混进状态区。

---

## 4. 空状态与稀疏数据不占位

- **没有数据的图表自动收起**成一行小图，不要占 40% 屏高画一条平线。
- 空表格显示一行提示即可，不要撑满。
- 值为 0 的指标可以保留（0 是有意义的），但**不要把 4 个 0 铺成 4 张大卡片**。

---

## 5. 章节标题

主内容区里的每个区块用统一的标题模式：

```
── 最近决策 ────────────────────────────────────  （右侧可放操作按钮）
```

- 小写字母间距的标签风格（`text-xs uppercase tracking-wider text-ink-lo`）
- 标题右侧一条延伸的细线，把标题和内容在视觉上绑定
- 与 DESIGN.md §3 的字号体系配合：**区块标题比正文小但更醒目**（靠字重和字距）

---

## 6. 检查清单

改完一个页面后逐条过：

- [ ] `xl` 下单页不滚动即可看到核心指标 + 主要内容
- [ ] 左栏按语义分组，组间有分隔
- [ ] 没有任何内部诊断值出现在状态区
- [ ] 没有一张图表占据超过 30% 屏高，除非它确实有那么多数据
- [ ] 空状态下页面不空洞
- [ ] `lg` 及以下左栏正确塌陷，不出现横向滚动
- [ ] 100% / 125% / 150% 缩放均无横向滚动
