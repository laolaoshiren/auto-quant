# 界面布局规范

**本文档是布局的契约。** 配色与字号见 [`DESIGN.md`](DESIGN.md) 与
[`tailwind.config.js`](tailwind.config.js)。

> **2026-11-10：三套模板收敛为唯一的 `quill`（静谧）。**
> 本文档描述的就是这一套骨架。另外两套（`classic` 顶部导航 / `console` 桌面窗口）
> 已在同一次重构中删除，理由与实测数据见
> `packages/web/ui-audit/phase-a/REPORT.md`。
>
> 模板系统本身仍在（`registerTemplate` + `templates/<目录>/` 自动发现），
> 第三方可以加自己的外壳；但**页面代码不需要知道当前是哪套模板** ——
> 它只描述"这一页有什么"，外壳决定那些东西放在哪（动作走 `<PageActions>`，
> 滚动容器由 `MAIN_SCROLL_ID` 约定）。

### 四条硬规则

**1. 导航在左侧，分两层：侧栏给分组、分段控件给组内页面。**

侧栏解决"配置页与盯盘页混在一列"的问题（组标题一眼分层）；分段控件把**当前分组**
的页面放在内容正上方，视线不用离开工作区。**不要再加第三层**（例如菜单栏）——
同一份导航出现两遍，用户每次都要重新判断该点哪个。

**2. 整个应用只有一个滚动层：`#main-scroll`（`.q-work`）。**

头部、分段控件、工具栏全部钉住；长表格滚动时它们不动。
页面里的"撑满剩余高度"布局（`.page-fill` / `h-full`）靠一条**确定高度链**：
`q-work` → `q-pad`（`height:100%`）→ `.page-fill`（`flex:1 1 auto`）→ 面板 → 表格体。
**不要**在中间插入没有 flex 上下文的普通 div —— 那会让表格按内容全高渲染、
溢出面板并压住页面末尾的内容（2026-11-10 实测：`/traders` 底部说明被压住 149–323px）。

**3. 页面动作统一进工具栏，危险动作永远最右。**

页面只说"有什么动作"（`<PageActions start end>`）；外壳决定位置。
`end` 槽里的动作（新建 / 保存 / 删除）必须靠右 —— 这件事不该由每个页面自己记得。

**4. 状态在头部，内部指标不常驻。**

推送状态、环境（模拟/实盘）、运行数这类**全局事实**放在头部/侧栏；
时钟偏移、API 权重这类**内部诊断值**只在越界时出现，并且带**后果**
（见 §5）。侧栏底部放操作员菜单（身份可见、退出要点两下）。

## 1. 侧栏

- 宽度默认 **212px**，可拖拽（`role="separator"` + 方向键 + Home 复位），
  范围 **184–320px**，记在 `localStorage`（`aq.quill.side`）。
- 为什么可拖：侧栏里是中文标签，「策略工作室」比「总览」宽一倍，固定宽度在
  某些字号/缩放下会截断；而截断的导航项读不出是什么页面。
- 分组顺序 = 使用频率：交易 → 系统 → 帮助。
- **`< 56em`（约 896px）**：侧栏收成抽屉，头部出现汉堡按钮。
  ⚠️ 断点必须与 `theme.css` 的 `@media (max-width: 56em)` 是同一个数；
  两处不一致会在中间宽度出现"侧栏收起了、汉堡还藏着"的空档。

## 2. 主列

- 头部 46px：汉堡（窄屏）/ 当前页面名 / 全局状态徽章 / 刷新 / ⌘K / 主题 / 模板切换。
- 分段控件 38px：**只在当前分组有 2 个以上页面时渲染**；否则省掉这一条高度。
- 工具栏 36px：**永远渲染**，哪怕当前页面没有动作 —— 条件渲染会让工作区在
  页面之间跳一下，而"这一页没有工具栏"用户看不出来（他只看到内容跳了）。
- 工作区：`overflow-y: auto`，唯一滚动容器，带 `id={MAIN_SCROLL_ID}`。

## 3. 两栏页面

`PageShell` 在 `xl` 及以上给 `3fr / 2fr`（约 60/40），右栏**自己滚动**并吸顶；
`xl` 以下单列堆叠。列表页（机器人、策略、行情）是整宽一张表，不渲染右栏。
右栏不设最大宽度：宽屏上把空间给图表和表格，不要留白边。

## 4. 常驻的 `backdrop-filter` 一律不用

**这条是踩过坑的。** 顶栏曾用 `bg-base-900/80 backdrop-blur`，结果在部分
GPU 驱动、远程桌面与虚拟显示环境下，Chrome 会创建"背景根"并把**整页内容
错误地提升进滤镜图层一起栅格化** —— 表现为整页均匀发虚、但布局完全正常。

毛玻璃在深色界面上几乎看不出来，代价却是这个渲染风险 + 每帧一次合成。
**头部、侧栏、工具栏、分段控件一律用不透明背景。**
对话框与通知的模糊**保留** —— 它们只在打开时存在。

## 5. 只显示状态，不显示内部指标

内部指标（时钟偏移、API 权重、快照数量、token 明细、本机时刻）**默认不出现**。

- **越界时才显示**，并且带**后果**而不是原始数值：
  `⚠ 时钟偏差 2.4s`（悬停说明会导致 `-1021`）比 `时钟 +2400 ms` 有用。
- 需要常驻诊断的场景（交易所诊断页）放在**专门的区块**里，不要混进状态区。

> 教训：顶栏曾常驻 `时钟 +22 ms` 与 `权重 59/2,400`。它们在正常运行时永远
> "没事"，看一百次有九十九次拿不到信息（操作者原话："似乎毫无意义"）。

## 6. 网格对齐：内容卡 `items-start`，指标卡等高

| 卡片类型 | 规则 | 为什么 |
| --- | --- | --- |
| **内容卡**（决策卡、说明卡） | **`items-start`** | 内容差异极大；撑等高会让短卡中间空出一大片（实测一张只有标题的决策卡被撑到 185px，其中 146px 是空白） |
| **指标卡**（一组 KPI 方块） | **等高**（不加 `items-start`） | 它们是**一个视觉单元**；高低不齐会让人以为不属于同一组 |

判断方法：**问自己"这几张卡是同一组数据，还是同一个列表里的不同条目？"**
同一组 → 等高；不同条目 → 各自高度。**不要无脑套用一个。**

## 7. 文字说的必须是事实

- 机器人停止时不要写「未连接交易所」—— 凭证是好的，只是没有实时读数。
- 没有成交记录时不要显示 `胜率 0.0%` —— 应该说「尚无已平仓交易」。
- **机器码（`stopped`、`open_long`、`EXPIRED`…）不得直接显示**，一律走
  `@aq/shared` 的标签映射（`traderStatusLabel` / `actionLabel` / `orderStatusLabel` /
  `orderPurposeLabel` / `orderTypeLabel` / `userRoleLabel` / `closeReasonLabel`）。

## 8. 检查清单

- [ ] 导航是"侧栏分组 + 分段控件"两层，没有第三层菜单栏
- [ ] 内容区是 `id={MAIN_SCROLL_ID}` 且是唯一滚动层
- [ ] 撑满类页面（`/traders`、`/market`）的表格在**自己容器内**滚动，页面末尾内容不被压住
- [ ] 页面动作走 `<PageActions>`，危险动作在最右
- [ ] 需要右栏的页面右栏**独立滚动**且撑满屏高
- [ ] 没有常驻的 `backdrop-filter`
- [ ] 状态区没有常驻的内部诊断值
- [ ] 装卡片的网格该 `items-start` 的有，指标组不该有的没有
- [ ] 每一条界面文案都成立（读一遍，问"这句话是真的吗"）
- [ ] 窄屏（< 56em）下侧栏收进抽屉、不出现横向滚动
- [ ] 100% / 125% / 150% 缩放均无横向滚动
